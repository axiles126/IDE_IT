Зв'язок із комп'ютером
HTML, CSS, JavaScript і Python виконуються прямо тут, на телефоні — зв'язок не потрібен. Python справжній, CPython у складі застосунку.

Node.js і Go на Android відсутні. Щоб запускати їх — а також Python із бібліотеками, яких немає у застосунку, — увімкни на комп'ютері node ide/server.js і вкажи адресу нижче. Кнопка «▸ на ПК» надсилає поточний файл на комп'ютер незалежно від мови.

Телефон під'єднано кабелем? Виконай на комп'ютері
adb reverse tcp:4321 tcp:4321
і залиш адресу http://127.0.0.1:4321.

По Wi-Fi — вкажи адресу комп'ютера в мережі, наприклад http://192.168.0.10:4321.
