# IDE_IT — середовище розробки

Локальна IDE у браузері з **справжніми** мовами: код виконується процесами на твоїй машині,
а не емуляцією. Без жодної зовнішньої залежності — треба лише Node.js для самого сервера.

## Запуск

```
node ide/server.js
```

або подвійним кліком по `ide/start.bat` (Windows).

У консолі зʼявиться посилання з токеном — відкрий його в браузері:

```
http://127.0.0.1:4321/?t=<токен>
```

Токен друкується щоразу новий. Щоб посилання не мінялося, задай свій:

```
set IDE_TOKEN=мій-токен && node ide/server.js        (cmd)
$env:IDE_TOKEN="мій-токен"; node ide/server.js       (PowerShell)
```

Інші параметри:

```
node ide/server.js D:\шлях\до\проєкту --port 5000
```

Без аргументу робочою текою стає `ide/workspace` — і при першому запуску туди
кладуться приклади на кожній мові.

## Що вміє

| Можливість | Як працює |
|---|---|
| **JavaScript / Node.js** | `node файл.js` — справжній процес, вивід у термінал |
| **TypeScript** | `node --experimental-strip-types файл.ts` |
| **Python** | `python -u файл.py`, зокрема `input()` через рядок терміналу |
| **Go** | `go run файл.go` — потрібен встановлений Go: <https://go.dev/dl/> |
| **HTML / CSS / JS** | кнопка «Переглянути» — сторінка віддається з диска, відносні шляхи працюють |
| **Термінал** | будь-яка команда в робочій теці: `npm install`, `pip install`, `go mod init`, `git` |
| **Файли** | створення, редагування, видалення, теки — усе прямо на диску |

Гарячі клавіші: **Ctrl+S** — зберегти, **Ctrl+Enter** — зберегти й запустити.

Редактор має нумерацію рядків, відступ табом, автовідступ нового рядка,
автозакриття дужок і лапок, позначку незбережених змін на вкладці.

## Інтерфейс

- **Провідник** — дерево файлів робочої теки (`node_modules`, `.git`, `__pycache__` згорнуті).
- **Редактор** — вкладки відкритих файлів.
- **Термінал** — вивід запусків і власні команди. Поки процес живий, рядок вводу
  надсилає текст у його `stdin` — так працює `input()` у Python.
- **Перегляд** — HTML-сторінка з робочої теки, оновлюється після кожного запуску.

На вузькому екрані панелі перемикаються кнопками внизу; на широкому видно всі одразу.
Окрема розкладка для альбомної орієнтації на низьких екранах.

## Безпека

Сервер слухає **лише 127.0.0.1** — з мережі він недоступний.
Кожен запит до API вимагає токен із посилання: без нього інший процес на машині
не зможе через IDE запускати команди. Усі шляхи перевіряються — вийти за межі
робочої теки не можна (`../` відкидається з кодом 403).

Термінал виконує команди з правами твого користувача — це звичайна оболонка,
поводься з нею так само уважно.

## Встановити Go

Go єдиний з трьох ще не стоїть на машині:

1. <https://go.dev/dl/> → інсталятор для Windows
2. перезапустити термінал (щоб оновився `PATH`)
3. у шапці IDE натиснути `↻` біля списку інструментів — індикатор `go` стане зеленим
