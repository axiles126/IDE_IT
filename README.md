# IDE_IT

Середовище розробки з трьох частин: застосунок на Android, локальний сервер для комп'ютера
і тренажер, що пояснює, як влаштована IT-сфера.

## Частини

### `app/` — застосунок на Android

Редактор коду на телефоні. Файли справжні, лежать у теці застосунку.

| Мова | Де виконується |
|---|---|
| HTML / CSS / JavaScript | на телефоні, рушієм WebView |
| **Python** | **на телефоні** — CPython 3.12 у складі застосунку (Chaquopy) |
| Node.js, Go | на комп'ютері, через сервер із `ide/` |
| Arduino, ESP32 | компіляція і прошивка на комп'ютері, керування з телефона |

Складання: `gradlew :app:assembleDebug`. Потрібен Android SDK; APK ≈ 48 МБ через CPython
для `arm64-v8a` і `x86_64` — прибрати `x86_64` з `abiFilters` у `app/build.gradle.kts`,
якщо емулятор не потрібен.

### `ide/` — середовище для комп'ютера

Сервер без залежностей + інтерфейс у браузері: провідник, редактор, термінал, перегляд
сторінок, робота з платами. Запуск: `node ide/server.js` або `ide/start.bat`.
Докладно — в [ide/README.md](ide/README.md).

Виконує **Node.js**, **Python**, **Go**, **TypeScript**, віддає HTML для перегляду
й прошиває **Arduino / ESP32** через `arduino-cli`.

### `ide_it_trainer.html` — тренажер IT-сфери

Одна сторінка без встановлення: дев'ять місій від каркаса сторінки до релізу, кожна
підписана роллю в команді — Frontend, QA, код-ревю, дизайн, юрист, бухгалтер, DevOps.
Перевірка завдань локальна, ШІ-наставники — додатково.

## Зв'язок телефона з комп'ютером

Кабелем:

```
adb reverse tcp:4321 tcp:4321
```

потім у застосунку на вкладці «ПК» вказати `http://127.0.0.1:4321` і токен із консолі сервера.
По Wi-Fi — адресу комп'ютера в мережі замість `127.0.0.1`.

## Що потрібно встановити

| Інструмент | Для чого | Обов'язково |
|---|---|---|
| [Node.js](https://nodejs.org/) | сервер `ide/` | так, для комп'ютерної частини |
| [Python](https://www.python.org/) | запуск `.py` на комп'ютері | ні (на телефоні Python вбудований) |
| [Go](https://go.dev/dl/) | запуск `.go` | ні |
| [arduino-cli](https://arduino.github.io/arduino-cli/latest/installation/) | Arduino та ESP32 | ні |
| Android SDK | складання застосунку | лише для складання |
